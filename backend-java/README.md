# SmartDesk Backend (Java)

This directory will contain the primary business backend for SmartDesk.

## Technology Stack
- **Framework**: Spring Boot
- **Build Tool**: Maven Wrapper (`mvnw` / `mvnw.cmd`)
- **Security**: Spring Security, JWT / secure sessions, RBAC
- **Persistence**: Spring Data JPA, Hibernate, PostgreSQL
- **Key Modules**:
  - Ticket lifecycle management
  - Intelligent routing engine (workload-aware & skill-based)
  - Escalation graph engine (BFS/DFS graph algorithms)
  - SLA policy & audit trail tracking

*Note: Initialized as placeholder during Phase 1. Java Spring Boot setup with Maven Wrapper will be established in subsequent phases.*
